Analytics

Usage statistics aggregated from the UsageEvent collection. All endpoints require analytics:read scope when using API keys. Heavy aggregations are cached in Redis for 10 minutes.

Common query parameters: All analytics endpoints accept ?from=2024-01-01&to=2024-01-31 (ISO 8601 dates). The daily endpoint also accepts &granularity=day|week|month.
GET/analytics/overview

Return aggregate usage totals for the authenticated user. Includes total messages, tokens, credits used, most-used model, and average latency for the specified period.

NameTypeRequiredDescription
fromstringoptionalStart date, ISO 8601. Defaults to 30 days ago
tostringoptionalEnd date, ISO 8601. Defaults to today
200 OK401 Unauthorized
GET/analytics/daily

Return usage data grouped by time bucket. Useful for charting usage over time.

NameTypeRequiredDescription
fromstringoptionalStart date, ISO 8601
tostringoptionalEnd date, ISO 8601
granularitystringoptionalday | week | month. Default: day
200 OK401 Unauthorized
GET/analytics/models

Return usage broken down by AI model total messages, tokens, and credits per model for the specified period.

200 OK401 Unauthorized
GET/analytics/api-keys

Return usage statistics per API key request count, tokens, and credits consumed per key. Only keys owned by the authenticated user are returned.

200 OK401 Unauthorized
