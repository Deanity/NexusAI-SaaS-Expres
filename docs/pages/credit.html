Credits

Credits are the currency of NexusAI. Every AI chat call deducts credits atomically balances can never go below zero. All credit changes produce a CreditLedger entry.

Credit actions (enum)

ValueDescription
purchaseManual credit purchase
subscription_grantCredits granted on subscription activation or renewal
ai_usageDeduction from AI chat usage
refundRefund credited back
admin_adjustmentManual admin add/deduct
welcome_bonus100-credit bonus on first email verification
GET/credits/balance

Return the authenticated user's current credit balance.

200 OK401 Unauthorized
GET/credits/history

Return paginated credit ledger entries for the authenticated user, ordered newest first. Each entry shows the action, amount, and running balance after the transaction.

NameTypeRequiredDescription
pageintegeroptionalDefault: 1
limitintegeroptionalDefault: 20, max: 100
actionstringoptionalFilter by CreditAction enum value
200 OK401 Unauthorized
POST/credits/purchase

Initiate a credit purchase. Returns a payment intent or redirect URL depending on the payment provider configured. On success, credits are added to the account and a ledger entry is created with action: purchase.

NameTypeRequiredDescription
amountintegerrequiredNumber of credits to purchase. Must be a positive integer
Note: The actual payment integration (Stripe / Midtrans) is configured via environment variables. This endpoint returns a checkoutUrl to redirect the user to the payment provider.
200 OK400 Validation error401 Unauthorized
