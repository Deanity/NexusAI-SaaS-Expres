Admin

Role required:  All endpoints in this section require role: admin on the authenticated user. Regular users will receive 403 Forbidden.

User Management

GET/admin/users

Return a paginated list of all registered users. Supports filtering by role, status, and email search.

NameTypeRequiredDescription
pageintegeroptionalDefault: 1
limitintegeroptionalDefault: 20, max: 100
rolestringoptionalFilter by role: user | admin
isActivebooleanoptionalFilter by active/banned status
qstringoptionalEmail substring search
200 OK401 Unauthorized403 Forbidden
GET/admin/users/:id

Return full details for a single user by ID, including subscription and credit summary.

200 OK403 Forbidden404 Not found
PATCH/admin/users/:id/ban

Set isActive: false on a user. The user cannot log in or call any authenticated endpoint. All active sessions are revoked.

NameTypeRequiredDescription
reasonstringoptionalReason recorded in the audit log
200 OK403 Forbidden404 Not found
PATCH/admin/users/:id/unban

Restore access by setting isActive: true. The user can log in again immediately.

200 OK403 Forbidden404 Not found

Credit Management

POST/admin/credits/adjust

Manually add or deduct credits from a user's account. All adjustments are atomic and produce a CreditLedger entry with action: admin_adjustment.

NameTypeRequiredDescription
userIdstringrequiredTarget user's MongoDB ObjectId
amountintegerrequiredPositive integer to add credits, negative to deduct. Deductions may not exceed the current balance
descriptionstringrequiredReason for the adjustment, recorded in the ledger
200 OK400 Validation error403 Forbidden422 Insufficient credits (for deductions)

Plan Management

POST/admin/plans

Create a new subscription plan. The slug must be globally unique and kebab-case.

NameTypeRequiredDescription
namestringrequiredDisplay name, e.g. Pro
slugstringrequiredUnique kebab-case identifier, e.g. pro
priceintegerrequiredPrice in smallest currency unit (cents for USD)
currencystringrequiredUSD or IDR
billingCyclestringrequiredmonthly | yearly | lifetime
creditsPerCycleintegerrequiredCredits granted at the start of each billing cycle
featuresobjectrequiredFeature limits: maxApiKeys, maxConversations, maxMessagesPerDay, allowedModels, priorityQueue, analyticsRetentionDays
201 Created400 Validation error403 Forbidden409 Slug already exists
PATCH/admin/plans/:id

Update any plan field. Changes to creditsPerCycle take effect on the next renewal cycle. Use isActive: false to retire a plan without deleting it.

200 OK400 Validation error403 Forbidden404 Not found

Platform Analytics

GET/admin/analytics/overview

Return platform-wide usage totals total users, total messages, tokens, credits consumed, and revenue metrics. Cached for 5 minutes.

200 OK403 Forbidden
GET/admin/analytics/users

Return per-user usage breakdown messages, tokens, and credits per user for the specified period. Useful for identifying top consumers.

NameTypeRequiredDescription
fromstringoptionalStart date, ISO 8601
tostringoptionalEnd date, ISO 8601
limitintegeroptionalMax users to return. Default: 50
200 OK403 Forbidden
