Conversation History

Full CRUD for conversation history. Users can only access their own conversations. Archived conversations are excluded from the default list unless ?archived=true is passed.

Pagination: All list endpoints support ?page=1&limit=20&sort=-createdAt. The response meta object contains page, limit, total, and totalPages.
GET/conversations

Return a paginated list of the authenticated user's conversations. Pinned conversations always appear first.

NameTypeRequiredDescription
pageintegeroptionalPage number. Default: 1
limitintegeroptionalItems per page. Default: 20, max: 100
sortstringoptionalSort field. Default: -lastMessageAt (newest first)
archivedbooleanoptionalInclude archived conversations. Default: false
200 OK401 Unauthorized
POST/conversations

Create an empty conversation. The title is auto-generated from the first message sent via POST /ai/chat.

NameTypeRequiredDescription
modelstringrequiredAI model for this conversation, e.g. gemini-1.5-flash
titlestringoptionalCustom title. Auto-generated from first message if omitted
systemPromptstringoptionalSystem instruction prepended to every chat call in this conversation
201 Created400 Validation error401 Unauthorized
GET/conversations/:id

Return a single conversation by ID, including metadata. Messages are paginated separately see GET messages.

NameTypeRequiredDescription
idstringrequiredMongoDB ObjectId of the conversation
200 OK403 Forbidden404 Not found
PATCH/conversations/:id

Update conversation metadata. Partial update only provided fields are changed.

NameTypeRequiredDescription
titlestringoptionalNew title, max 60 characters
isPinnedbooleanoptionalPin/unpin conversation. Pinned conversations appear first in the list
systemPromptstringoptionalUpdate the system prompt for future messages in this conversation
200 OK403 Forbidden404 Not found
DELETE/conversations/:id

Soft-delete (archive) a conversation. Sets isArchived: true. The conversation is excluded from the default list and can be restored via PATCH.

200 OK403 Forbidden404 Not found
GET/conversations/:id/messages

Return paginated messages for a conversation, ordered oldest first. Default limit: 50. Max limit: 100.

NameTypeRequiredDescription
pageintegeroptionalPage number. Default: 1
limitintegeroptionalMessages per page. Default: 50, max: 100
200 OK403 Forbidden404 Not found
DELETE/conversations/:id/messages

Delete all messages in a conversation but keep the conversation itself. The messageCount counter is reset to 0.

Irreversible: All messages are permanently deleted. The conversation metadata (title, model, systemPrompt) is preserved.
200 OK403 Forbidden404 Not found
