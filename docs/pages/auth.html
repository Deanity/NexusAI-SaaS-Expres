Authentication

All auth endpoints live under /api/v1/auth. Access tokens expire in 15 minutes. Refresh tokens (7-day expiry) are stored as httpOnly Secure cookies they are never returned in the response body.

POST /auth/register

Create a new user account. Queues a verification email. Grants a 100-credit welcome bonus on first email verification.

NameTypeRequiredDescription
namestringrequiredFull display name
emailstringrequiredUnique email address, stored lowercase
passwordstringrequiredMin 8 chars, must include 1 uppercase letter and 1 number
FieldTypeDescription
successbooleanAlways true on success
messagestringHuman-readable confirmation
data.userobjectCreated user object (password excluded)
201 Created 400 Validation error 409 Email already registered
request
bash
curl -X POST https://api.nexusai.dev/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Jane Dev","email":"jane@example.com","password":"SecurePass1"}'
response
json
{"success":true,"message":"Registration successful. Please verify your email.","data":{"user":{"_id":"...","name":"Jane Dev","email":"jane@example.com","role":"user","isEmailVerified":false,"credits":0}}}
POST /auth/login

Authenticate and receive an access token in the response body. The refresh token is set as an httpOnly cookie automatically.

NameTypeRequiredDescription
emailstringrequiredAccount email
passwordstringrequiredAccount password

The accessToken is returned in the body. The refresh token is only in the cookie.

POST /auth/refresh

Rotate your session. Sends the current refresh token cookie and receives a new access token + rotated refresh token cookie. The old refresh token is immediately invalidated.

No request body required the refresh token is read from the httpOnly cookie.
200 OK 401 Invalid or expired refresh token
POST /auth/logout

Revoke the current session. Deletes the Redis refresh token entry and marks the DB record as revoked. Requires a valid access token.

200 OK 401 Unauthorized
POST /auth/logout-all

Revoke all active sessions for the authenticated user. Use when you suspect a device has been compromised.

200 OK 401 Unauthorized
POST /auth/verify-email

Verify a registered email address using the token sent to the inbox. On first verification, a 100-credit welcome bonus is credited.

NameTypeRequiredDescription
tokenstringrequired64-character hex token from the verification email
200 OK 400 Invalid or expired token 409 Already verified
POST /auth/resend-verification

Re-send the email verification link. Rate-limited to prevent abuse.

NameTypeRequiredDescription
emailstringrequiredThe unverified account email
200 OK 400 Already verified 429 Too many requests
POST /auth/forgot-password

Request a password reset email. Always returns 200 regardless of whether the email exists, to prevent user enumeration.

NameTypeRequiredDescription
emailstringrequiredEmail of the account to reset
200 OK
POST /auth/reset-password

Submit a new password using the reset token from the email. The token is valid for 1 hour and can only be used once.

NameTypeRequiredDescription
tokenstringrequired64-character hex token from the reset email (expires in 1 hour)
passwordstringrequiredNew password min 8 chars, 1 uppercase, 1 number
200 OK 400 Invalid or expired token 422 Password does not meet requirements
