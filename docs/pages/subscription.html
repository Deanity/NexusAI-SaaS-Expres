Subscriptions

Browse available plans, subscribe, and manage your subscription. Plan endpoints are public no auth required to view plans.

Subscription lifecycle

register → Free (auto-assigned) Free → upgrade → ACTIVE ACTIVE → cancel → ACTIVE (until period end) → CANCELLED ACTIVE → payment fail → PAST_DUE → retry → ACTIVE or EXPIRED

Status values

ValueDescription
activePlan is currently active and credits are granted
trialingIn a free trial period
past_duePayment failed, awaiting retry
cancelledCancelled active until currentPeriodEnd
expiredPeriod ended with no renewal

GET/plans

Return all active subscription plans. Public endpoint no authentication required.

200 OK
GET/plans/:slug

Return a single plan by its slug (e.g. pro, starter). Public endpoint.

200 OK404 Not found
POST/subscriptions

Subscribe to a plan. Immediately grants creditsPerCycle to the user. Only one active subscription is allowed at a time upgrading replaces the current plan.

NameTypeRequiredDescription
planIdstringrequiredMongoDB ObjectId of the plan to subscribe to
201 Created400 Validation error401 Unauthorized404 Plan not found
GET/subscriptions/current

Return the authenticated user's current active subscription, including the nested plan details.

200 OK401 Unauthorized404 No active subscription
POST/subscriptions/cancel

Cancel the current subscription at the end of the billing period. Access continues until currentPeriodEnd. Sets cancelAtPeriodEnd: true.

Cancellation is immediate in terms of future renewals it does not terminate access early. Downgrading to Free happens automatically at period end.
200 OK401 Unauthorized404 No active subscription
