API Keys

API keys allow programmatic access without using your user credentials. Each key has granular scopes and can be restricted to specific IP addresses.

Key format: nxai_ followed by 40 random base62 characters total 45 characters. The full key is shown once on creation only. Only the prefix (nxai_xxxxxxxx) and a SHA-256 hash are stored.
Using API keys: Include the full key in the x-api-key header instead of the Authorization header. The key is validated against its hash and checked for scope, expiry, and IP whitelist.

Available scopes

ScopeAccess granted
chat:writeSend messages via POST /ai/chat
history:readRead conversations and messages
history:deleteArchive or clear conversations
analytics:readAccess usage analytics endpoints
credits:readView credit balance and history
GET/api-keys

List all API keys for the authenticated user. The full key is never returned only the prefix and metadata.

200 OK401 Unauthorized
POST/api-keys

Create a new API key. The full key (nxai_...) is returned once in this response only. Store it securely it cannot be retrieved again.

NameTypeRequiredDescription
namestringrequiredUser-defined label for this key, e.g. production
scopesstring[]requiredArray of scope strings, e.g. ["chat:write","history:read"]
expiresAtstringoptionalISO 8601 datetime. Omit for a key that never expires
ipWhiteliststring[]optionalAllowed IP addresses. Empty array = allow all
201 Created400 Validation error409 Name already in use422 Key limit reached
PATCH/api-keys/:id

Update an API key's name, scopes, IP whitelist, or expiry. The key value is not changed.

NameTypeRequiredDescription
namestringoptionalNew label
scopesstring[]optionalReplaces the current scope array
expiresAtstringoptionalNew expiry datetime or null to remove expiry
ipWhiteliststring[]optionalReplaces the current IP whitelist
200 OK403 Forbidden404 Not found
DELETE/api-keys/:id

Revoke an API key. Sets isActive: false. Any request using this key will immediately receive 401 Unauthorized.

200 OK403 Forbidden404 Not found
POST/api-keys/:id/rotate

Generate a new key value for the same key entry. The old key is immediately invalidated. All settings (name, scopes, IP whitelist, expiry) are preserved. The new full key is returned once.

Breaking change: All systems using the old key must be updated immediately after rotation.
200 OK403 Forbidden404 Not found

Using API key header
bash
curl -X POST https://api.nexusai.dev/api/v1/ai/chat \
  -H "x-api-key: nxai_A7bK9mP3qR6wX2nL4vE8..." \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-1.5-flash","message":"Hello"}'
