AI Chat

Send messages to a supported AI model and receive a response. Each call deducts credits based on tokens consumed. Supports Server-Sent Events (SSE) streaming.

POST/ai/chat

Send a message to an AI model. Provide a conversationId to continue an existing conversation, or omit it to start a new one. Credits are deducted only on success.

NameTypeRequiredDescription
AuthorizationstringrequiredBearer <accessToken> or use x-api-key with chat:write scope
Content-Typestringrequiredapplication/json
NameTypeRequiredDescription
modelstringrequiredModel identifier, e.g. gemini-1.5-flash. Must be in ENABLED_MODELS
messagestringrequiredThe user's message text
conversationIdstringoptionalExisting conversation ID to continue. Omit to create a new conversation
systemPromptstringoptionalSystem instruction only used when creating a new conversation
streambooleanoptionalSet true to receive a streaming SSE response. Default: false
200 OK 400 Validation error 401 Unauthorized 422 Insufficient credits 422 MODEL_NOT_AVAILABLE 503 Provider error
request
bash
curl -X POST https://api.nexusai.dev/api/v1/ai/chat \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-1.5-flash",
    "message": "Explain REST APIs in one paragraph."
  }'
response
json
{"success":true,"message":"Chat response","data":{"conversationId":"...","message":{"role":"assistant","content":"REST APIs use HTTP methods...","tokensUsed":148,"creditsDeducted":1}}}

Streaming (SSE)

Set stream: true in the request body to receive a text/event-stream response. Each event contains a JSON delta:

SSE streamtext
data: {"delta":"REST "}
data: {"delta":"APIs "}
data: {"delta":"use HTTP..."}
data: {"done":true,"tokensUsed":148,"creditsDeducted":1}

On stream complete, the full response is saved as a single Message document. Credits are deducted only after the stream completes successfully.

Credit deduction flow

  1. Pre-check: estimate token count, verify user has sufficient credits
  2. Call model provider API (or open SSE stream)
  3. On success: save Message document with actual token count
  4. Atomic deduct: MongoDB transaction checks credits >= amount then decrements
  5. Write CreditLedger entry with action: ai_usage
  6. Log UsageEvent for analytics
  7. On provider error: no credits are deducted, return 503
